# Feladatsor:
## 1. Lépés – HTML Struktúra
Hozz létre egy index.html fájlt, és biztosítsd, hogy az oldal megfelelő HTML struktúrával rendelkezzen.

✅ A fájlnak tartalmaznia kell:

Egy <html> elemet, amelynek lang="hu" attribútuma van.
Egy <head> szekciót, amely tartalmazza:
Egy <meta charset="UTF-8"> elemet a karakterkódolás beállításához.
Egy <title> elemet, amelynek értéke "Kék téglalapok".
Egy <body> elemet, amely tartalmaz egy div.container elemet.

## 2. Lépés – A Téglalapok Elhelyezése
A container osztályú div belsejében helyezz el 6 darab div.rectangle elemet.

✅ Elvárás:

A container div 6 darab rectangle osztályú divet tartalmazzon.
